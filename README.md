# 🌸 ร้านข้าวขาหมูพาสเทล "หวานละมุน" (Wan Lamun Stewed Pork Leg)

เว็บแอปพลิเคชันร้านข้าวขาหมูตกแต่งด้วยธีมสีพาสเทลแสนหวานและอบอุ่น พร้อมระบบฐานข้อมูล SQLite ครบวงจรสำหรับสั่งอาหารหน้าร้านและระบบจัดการออเดอร์หลังร้าน (Kitchen POS / Admin)

---

## 🎨 จุดเด่นและฟีเจอร์เด่นของระบบ

1. **ธีมสีพาสเทล ละมุนตา สบายใจ (Pastel Aesthetics)**
   - โทนสีครีมเนย, ชมพูพีช, เขียวมิ้นต์, ม่วงลาเวนเดอร์ และสีน้ำตาลคาราเมลพะโล้
   - ตัวอักษรน่ารัก สไตล์คาเฟ่โมเดิร์น อ่านง่าย ใช้งานลื่นไหลบนทุกอุปกรณ์ (Responsive Mobile & Desktop)
   - มีเสียงแจ้งเตือนแบบ Web Audio API แสนน่ารักเมื่อกดสั่งอาหารหรือเปลี่ยนสถานะ

2. **ระบบฐานข้อมูล SQLite ในตัว (Persistent Database)**
   - ใช้ `khamoo.db` จัดเก็บข้อมูลจริงทั้งหมด ไม่สูญหายเมื่อปิดโปรแกรม
   - รองรับข้อมูลหมวดหมู่ (Categories), เมนูอาหาร (Menu Items), คำสั่งซื้อ (Orders & Order Items), รีวิว (Reviews) และการตั้งค่าร้าน (Settings)
   - ไม่ต้องติดตั้ง Database เพิ่มเติม รันผ่าน Node.js ได้ทันที 100%

3. **ระบบสำหรับลูกค้า (Customer Storefront)**
   - เลือกดูเมนูตามหมวดหมู่ (ข้าวขาหมู, กับข้าว, ซุปต้มตุ๋น, เครื่องเคียง, เครื่องดื่ม & ของหวาน)
   - ค้นหาเมนูอาหารแบบ Real-time
   - สั่งปรับแต่งได้ตามใจ: พิเศษ/ธรรมดา, เนื้อล้วน/หนังล้วน/เนื้อหนัง/คากิ, เพิ่มไข่ยางมะตูม, เพิ่มไส้, โน้ตกำกับ
   - ระบบตะกร้าสินค้า (Cart Drawer) คำนวณยอดเงินทันที
   - รองรับการสั่ง: ทานที่ร้าน (ระบุเลขโต๊ะ), สั่งกลับบ้าน, หรือเดลิเวอรี่ (ระบุที่อยู่)
   - ใบเสร็จสรุปออเดอร์ พร้อม QR Code จำลอง PromptPay สำหรับชำระเงิน
   - ระบบติดตามสถานะอาหาร (Live Order Tracker) ด้วยเลขที่ออเดอร์
   - ระบบเขียนรีวิวและให้คะแนนดาวร้าน

4. **ระบบหลังร้าน / จัดการครัว (Kitchen POS & Admin Dashboard)**
   - เปิดดูได้ที่: `http://localhost:3000/admin.html`
   - บอร์ดคำสั่งซื้อสด (Live Orders) จัดการสถานะ: รับออเดอร์ -> กำลังปรุง 🍳 -> พร้อมเสิร์ฟ 🛵 -> เสร็จสิ้น ✅
   - พิมพ์ใบเสร็จย่อสำหรับติดกล่องหรือส่งให้โต๊ะ
   - สรุปยอดขายรวมวันนี้, สถิติออเดอร์, และเมนูขายดี 5 อันดับแรก
   - จัดการเมนู: เพิ่มเมนูใหม่, แก้ไขราคา, เปิด/ปิดของหมด (In Stock / Out of Stock), ลบเมนู
   - ดูรีวิวและคะแนนจากลูกค้าแบบเรียลไทม์

## 🚀 วิธีการเปิดใช้งาน

### วิธีที่ 1: ดับเบิลคลิกไฟล์เดียว (ง่ายที่สุด)
- ดับเบิลคลิกที่ไฟล์ **`start.bat`** ในโฟลเดอร์ `D:\khamoo`
- โปรแกรมจะเปิดหน้าเว็บ `http://localhost:3000` ขึ้นมาให้อัตโนมัติ

### วิธีที่ 2: รันผ่าน Command Prompt / Terminal
```bash
cd D:\khamoo
node server.js
```
หรือ
```bash
npm start
```

- เข้าใช้งานหน้าสั่งอาหาร: **[http://localhost:3000](http://localhost:3000)**
- เข้าใช้งานหน้าระบบจัดการหลังร้าน / ครัว: **[http://localhost:3000/admin.html](http://localhost:3000/admin.html)**
